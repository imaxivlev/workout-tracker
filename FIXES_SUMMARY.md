## Технические детали

### Структура WOD формы:
```
.wod-exercise-row (контейнер)
  └── .wod-row-scroller (основной layout)
      ├── .wod-exercise-name (поле упражнения)
      └── .wod-fields-scroll (контейнер полей)
          ├── .single-reps-container / .ladder-reps-container (повторения)
          └── .wod-weight (вес)
  └── .btn-icon (кнопка удаления, absolute)
```

### Ключевые изменения в CSS:

**Десктоп:**
- Grid layout: `1fr 1fr` для основного ряда
- Nested grid: `1fr auto` для полей (повторения + вес)
- Вес прижат к правому краю через `justify-self: end`
- Ширина поля веса: **80px**

**Планшет/Мобильные (без лесенки):**
- Вертикальная компоновка: `flex-direction: column`
- Упражнение сверху, поля снизу
- **На мобильных поля "повт." и "вес" занимают по 50% ширины** (flex: 1 1 auto)

**Мобильные (с лесенкой):**
- Если раундов ≤ 3: все поля в одной строке с горизонтальной прокруткой
- Если раундов > 3: поле "вес" переносится на новую строку (класс `.many-rounds`)
- Класс `.many-rounds` добавляется автоматически через JavaScript

### Календарь:

**Поля "от" и "до":**
- При клике поле становится редактируемым (removeAttribute('readonly'))
- После ввода и blur парсится формат дд.мм.гггг
- Валидация даты и автоматическое обновление календаря
- Если дата "до" раньше даты "от" - даты меняются местами

**Адаптивность:**
- На мобильных календарь не выходит за пределы экрана
- Добавлены ограничения по ширине и overflow
- Уменьшены размеры элементов для лучшей читаемости
