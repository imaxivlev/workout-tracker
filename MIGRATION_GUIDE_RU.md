# Инструкция по переносу проекта в KIRO

## 1. Загрузка в KIRO

1.  Найдите файл архива:
    `d:\.gemini\.gemini\antigravity\playground\CrossFit_Tracker_Backup.zip`
2.  Перенесите этот файл в рабочее окружение KIRO (или распакуйте его в рабочей папке KIRO).
3.  Если вы распаковали архив, откройте терминал в папке проекта.
4.  Восстановите зависимости (так как мы исключили тяжелую папку `node_modules`):
    ```bash
    npm install
    ```
5.  Запустите проект для проверки:
    ```bash
    npm run dev
    ```

## 2. Работа в KIRO

Продолжайте разработку как обычно. Все исходные файлы (`app/`, `mockups/`, стили и скрипты) сохранены.

## 3. Возврат в Antigravity (Google)

Когда вы решите вернуть проект обратно:

1.  В KIRO создайте такой же архив, исключив `node_modules` и `.next`.
    *В терминале можно использовать:*
    ```bash
    zip -r CrossFit_Tracker_New_Backup.zip . -x "node_modules/*" ".next/*"
    ```
    *Или просто заархивируйте папку средствами системы, предварительно удалив `node_modules`.*
2.  Перенесите архив обратно на этот компьютер.
3.  Распакуйте его с заменой файлов в эту папку:
    `d:\.gemini\.gemini\antigravity\playground\CrossFit_Tracker`
4.  Снова запустите установку зависимостей (на всякий случай):
    ```bash
    npm install
    ```
5.  Проект снова готов к работе в Antigravity.
