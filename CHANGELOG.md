# Changelog - Исправления верстки CrossFit Tracker

## Дата: 16 февраля 2026

### Исправлено

#### 1. Поля упражнений WOD (Десктоп и Планшет)

**Проблема 1.1: Без лесенки - поля "повт." и "вес" сбивались**
- Удалены все `!important` из CSS
- Исправлена grid-структура: теперь поля корректно занимают 50% пространства каждое
- Поля "повт." и "вес" теперь равномерно распределяются в доступном пространстве

**Проблема 1.2: С лесенкой - неправильные ширины полей**
- Поле "вес" теперь имеет фиксированную ширину 65px
- Поля для раундов (Р1, Р2, Р3...) имеют минимальную ширину 65px и растягиваются по доступному пространству
- Прокрутка включается только когда действительно необходимо

#### 2. Календарь на странице "История"

**Добавлено:**
- Два поля для отображения выбранных дат в формате дд.мм.гггг
- Поле "От" - для первой выбранной даты
- Поле "До" - для второй выбранной даты
- Логика заполнения: 1-й клик → первая дата, 2-й клик → вторая дата, 3-й клик → снова первая дата
- Поля автоматически обновляются при выборе пресетов (Сегодня, Вчера, Неделя и т.д.)

**Адаптивность:**
- На мобильных (<768px) поля располагаются вертикально (одно под другим)
- На десктопе - горизонтально (рядом)

#### 3. Мобильное меню

**Добавлено:**
- Ссылка "История" в мобильное нижнее меню
- Иконка часов для визуального обозначения
- Корректная навигация и подсветка активного пункта

#### 4. Очистка CSS

**Удалено:**
- Все лишние `!important` из стилей (было ~30+, осталось 0)
- Минимизированы инлайновые стили в HTML
- Улучшена специфичность селекторов для корректной работы без `!important`

### Технические детали

**Файлы изменены:**
- `public/workout-tracker/index.html` - добавлены поля дат и ссылка в меню
- `public/workout-tracker/mvp-styles.css` - исправлена grid-структура WOD, удалены `!important`, добавлены стили для полей дат
- `public/workout-tracker/mvp-script-v3.js` - добавлена функция `updateDateInputs()`, обновлена логика выбора дат

**Совместимость:**
- Десктоп (>768px) - полностью исправлено
- Планшет (481-768px) - полностью исправлено
- Мобильные (<480px) - полностью исправлено

### Результат

Все указанные проблемы решены:
✅ Поля WOD корректно отображаются на всех разрешениях
✅ Календарь имеет поля для выбора дат
✅ Мобильное меню содержит ссылку на историю
✅ CSS очищен от избыточных `!important`
✅ Верстка стала более поддерживаемой и предсказуемой
