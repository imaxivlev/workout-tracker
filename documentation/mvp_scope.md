# MVP Scope: CrossFit Workout Tracker

## Философия MVP

**Цель:** Создать работающее приложение для личного использования одним атлетом, которое решает основную проблему - отслеживание тренировок и прогресса.

**Принцип:** Минимум функций, максимум качества. Каждая фича должна работать идеально.

---

## Что входит в MVP

### 1. Создание тренировок

**Структура тренировки:**
- Тренировка может состоять из нескольких блоков (Skill + WOD, Skill + Skill, только WOD и т.д.)
- Пользователь собирает тренировку как конструктор

**Skill (отработка техники):**
- Название упражнения (умный ввод с автодополнением и сохранением новых)
- Количество подходов (выбор 1-10)
- Поле ввода повторений для КАЖДОГО подхода
- Максимальный вес
- *Умная подсказка:* "В прошлый раз вы делали..." (только если есть история)

**WOD (тренировка дня):**
- Название WOD
- Тип (EMOM, AMRAP, For Time, For Load)
- Время/раунды/повторения
- Список упражнений с весами
- Результат
- Rx/Scaled

### 2. История тренировок

#### Главная страница (Dashboard)
- **Показатели:**
  - Кол-во тренировок в месяце
  - Тоннаж за месяц (сумма весов * повторения)
  - Текущий стрик (дней подряд/недель подряд)
- **Лента:**
  - Карточки тренировок (могут содержать и Skill, и WOD)

### 3. Личная статистика

- График тоннажа
- Личные рекорды (PR) по упражнениям
- История конкретного упражнения

**Уведомления:**
- "В прошлый раз вы делали это упражнение [дата], результат: [результат]"

### 4. Профиль пользователя

**Минимальная информация:**
- Имя
- Аватар (опционально)
- Пол
- Email (для входа)

### 5. Аутентификация

- Регистрация (email + пароль)
- Вход
- Выход
- Восстановление пароля (опционально для MVP)

### 6. PWA функционал

- Установка на домашний экран
- Работа без интерфейса браузера (standalone mode)
- Базовое кэширование статики
- **Требует интернета** для работы с данными

## Архитектура с заделом на будущее

### База данных

**Используем сейчас:**
- `users` - с полем `role` (всегда 'visitor' в MVP)
- `workouts` - с полем `club_id` (всегда NULL в MVP)
- `exercises` - справочник упражнений
- `user_results` - результаты тренировок
- `workout_history` - история

**Готовим для будущего (таблицы создаем, но не используем):**
- `clubs` - клубы
- `club_members` - участники клубов
- `badges` - достижения
- `user_badges` - полученные достижения

### API Endpoints

**MVP:**
- `POST /api/auth/register`
- `POST /api/auth/login`
- `GET /api/auth/me`
- `POST /api/workouts` - создание
- `GET /api/workouts` - список с фильтрами
- `GET /api/workouts/:id` - детали
- `PUT /api/workouts/:id` - редактирование
- `DELETE /api/workouts/:id` - удаление
- `GET /api/exercises` - список упражнений
- `GET /api/exercises/search` - поиск
- `GET /api/stats/personal` - личная статистика
- `GET /api/profile` - профиль
- `PUT /api/profile` - обновление профиля

**Заготовки для будущего (структура, но не реализация):**
- `/api/clubs/*` - управление клубами
- `/api/leaderboard/*` - лидерборды
- `/api/badges/*` - достижения

## UI/UX для MVP

### Экраны

1. **Главная** - список последних тренировок + кнопка "Создать"
2. **Создание тренировки** - форма Skill/WOD
3. **История** - список всех тренировок с фильтрами
4. **Статистика** - графики и PR
5. **Профиль** - настройки пользователя

### Навигация

Простое меню:
- 🏠 Главная
- ➕ Создать
- 📊 Статистика
- 👤 Профиль

## Критерии готовности MVP

### Must Have (обязательно)

- ✅ Пользователь может зарегистрироваться
- ✅ Пользователь может создать Skill тренировку
- ✅ Пользователь может создать WOD тренировку
- ✅ Пользователь видит историю всех тренировок
- ✅ Пользователь может редактировать результаты
- ✅ Пользователь видит личные рекорды
- ✅ Приложение работает как PWA (можно установить)
- ✅ Дизайн выглядит современно и мотивирует

### Nice to Have (желательно)

- 📈 График прогресса по упражнению
- 🔍 Умный поиск упражнений (fuzzy)
- 📱 Адаптивный дизайн (мобильные)
- ⚡ Быстрый ввод (минимум кликов)

### Won't Have (точно не будет в MVP)

- Всё из раздела "Что НЕ входит в MVP"

## Технические решения

### Стек (без изменений)
- Next.js 14 + TypeScript
- PostgreSQL + Prisma
- NextAuth.js
- Tailwind CSS

### Упрощения для MVP
- Без Redis (кэширование не критично)
- Без сложной аналитики
- Без real-time обновлений
- Простая валидация форм
