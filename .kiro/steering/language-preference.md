# Language Preference

## Communication Language

All project documentation, specifications, code comments, and chat communication MUST be in Russian language.

This includes:
- Requirements documents (requirements.md)
- Design documents (design.md)
- Task lists (tasks.md)
- Code comments
- Git commit messages
- Chat responses
- All user-facing text

## Exceptions

- Code identifiers (variable names, function names, class names) should follow standard English naming conventions for code readability
- Technical terms that are commonly used in English (e.g., "property-based testing", "EARS patterns") can be kept in English when appropriate
