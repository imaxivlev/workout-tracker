# Bugfix Requirements Document

## Введение

Продакшн версия приложения CrossFit Tracker (https://crossfitapp.ru/) имеет значительные расхождения с эталонными макетами, которые находятся в `public/workout-tracker/index.html`. Эти расхождения касаются как визуального представления, так и функциональности компонентов. Необходимо привести продакшн версию в полное соответствие с эталонными макетами.

Эталонные файлы:
- HTML: `public/workout-tracker/index.html`
- CSS: `public/workout-tracker/mvp-styles.css`
- JS: `public/workout-tracker/mvp-script-v3.js`

Текущая реализация (Next.js):
- Главная: `app/dashboard/page.tsx`
- История: `app/dashboard/workouts/page.tsx`
- Создание: `app/dashboard/workouts/new/page.tsx`
- Детали: `app/dashboard/workouts/[id]/page.tsx`
- Статистика по упражнению: `app/dashboard/exercise/[id]/page.tsx`
- Layout: `app/dashboard/layout.tsx`
- Стили: `app/globals.css`

## Bug Analysis

### Current Behavior (Defect)

#### 1. Главная страница (dashboard/page.tsx)

1.1 WHEN пользователь открывает главную страницу THEN система отображает только карточку "Тоннаж в этом месяце" вместо трех карточек статистики

1.2 WHEN пользователь открывает главную страницу THEN система не отображает карточку "Лучший вес" с названием упражнения и датой (например, "120 кг, Back Squat, 12 фев")

1.3 WHEN пользователь открывает главную страницу THEN система не отображает карточку "Тренировочных дней подряд" с иконкой огня

#### 2. Страница "История" (dashboard/workouts/page.tsx)

1.4 WHEN пользователь открывает страницу истории THEN система отображает стандартный HTML5 `<input type="date">` вместо кастомного date picker с календарем

1.5 WHEN пользователь хочет выбрать период THEN система не предоставляет пресеты: "Сегодня", "Вчера", "Неделя", "Месяц", "Квартал", "За все время", "Период"

1.6 WHEN пользователь открывает календарь THEN система не отображает визуальный календарь на 3 месяца с индикаторами тренировок (зеленые/красные точки для Skill/WOD)

1.7 WHEN пользователь хочет отфильтровать тренировки THEN система не предоставляет фильтр "Фильтр по упражнению" с dropdown списком упражнений

1.8 WHEN пользователь просматривает историю с пагинацией THEN система отображает упрощенную пагинацию без логики "Пред.", "1", "2", "...", "N-1", "N", "След."

#### 3. Страница "Статистика" (отсутствует)

1.9 WHEN пользователь переходит по ссылке "Статистика" в навигации THEN система перенаправляет на `/dashboard/exercise` вместо общей страницы статистики `/dashboard/stats`

1.10 WHEN пользователь хочет просмотреть общую статистику THEN система не предоставляет селектор периода: "Неделя", "Месяц", "Год", "Всё время"

1.11 WHEN пользователь хочет просмотреть общую статистику THEN система не отображает сетку статистики: "Тренировок", "Skill сессий", "WOD сессий", "Новых PR"

1.12 WHEN пользователь хочет просмотреть личные рекорды THEN система не отображает секцию "Личные рекорды" со списком PR по разным упражнениям

1.13 WHEN пользователь хочет просмотреть прогресс THEN система не отображает график "Прогресс по упражнению" с выбором упражнения и детализации (по дням/неделям/месяцам)

#### 4. Страница создания тренировки (dashboard/workouts/new/page.tsx)

1.14 WHEN пользователь добавляет Skill блок THEN система не отображает селектор "Количество подходов" (1-12)

1.15 WHEN пользователь добавляет Skill блок THEN система не отображает поле "Максимальный вес (кг)"

1.16 WHEN пользователь выбирает упражнение в Skill блоке THEN система не отображает подсказку "В прошлый раз: X кг (дата)"

1.17 WHEN пользователь вводит подходы в Skill блоке THEN система отображает поля ввода в неправильном формате (не отдельные инпуты для повторений всех подходов, затем отдельные инпуты для весов)

1.18 WHEN пользователь добавляет WOD блок с режимом "Лесенка" THEN система не отображает поле "Количество раундов"

1.19 WHEN пользователь выбирает режим "Лесенка" в WOD блоке THEN система не отображает отдельные инпуты для повторений каждого раунда (Р1, Р2, Р3...)

1.20 WHEN пользователь выбирает кардио упражнение в WOD блоке THEN система не скрывает автоматически поле "Вес" для кардио упражнений (Bike, Row, Run, SkiErg)

1.21 WHEN пользователь вводит результат "For Time" в WOD блоке THEN система не применяет маску ввода MM:SS

#### 5. Страница детального просмотра (dashboard/workouts/[id]/page.tsx)

1.22 WHEN пользователь открывает детальный просмотр тренировки THEN система не отображает кнопку "✏️ Редактировать" в header

1.23 WHEN пользователь просматривает Skill блок в деталях THEN система не отображает расчет 1RM для каждого подхода в таблице

1.24 WHEN пользователь просматривает детали тренировки THEN система отображает дизайн блоков, отличающийся от эталона

#### 6. Навигация (dashboard/layout.tsx)

1.25 WHEN пользователь кликает на "Статистика" в навигации THEN система перенаправляет на `/dashboard/exercise` вместо `/dashboard/stats`

1.26 WHEN пользователь использует навигацию THEN система не предоставляет страницу `/dashboard/stats` с общей статистикой

### Expected Behavior (Correct)

#### 1. Главная страница

2.1 WHEN пользователь открывает главную страницу THEN система SHALL отображать три карточки статистики: "Тренировок в этом месяце", "Лучший вес", "Тренировочных дней подряд"

2.2 WHEN пользователь открывает главную страницу THEN система SHALL отображать карточку "Лучший вес" с форматом: "120 кг", "Back Squat", "12 фев"

2.3 WHEN пользователь открывает главную страницу THEN система SHALL отображать карточку "Тренировочных дней подряд" с иконкой огня "🔥" и числом

#### 2. Страница "История"

2.4 WHEN пользователь открывает страницу истории THEN система SHALL отображать кастомный date picker с визуальным календарем на 3 месяца

2.5 WHEN пользователь кликает на поле выбора периода THEN система SHALL отображать dropdown с пресетами: "Сегодня", "Вчера", "Неделя", "Месяц", "Квартал", "За все время", "Период"

2.6 WHEN пользователь открывает календарь THEN система SHALL отображать три месяца с индикаторами тренировок (зеленые точки для Skill, красные для WOD)

2.7 WHEN пользователь открывает страницу истории THEN система SHALL отображать фильтр "Фильтр по упражнению" с dropdown списком всех упражнений

2.8 WHEN пользователь просматривает историю с пагинацией THEN система SHALL отображать пагинацию в формате: "Пред.", "1", "2", "...", "N-1", "N", "След."

#### 3. Страница "Статистика"

2.9 WHEN пользователь переходит по ссылке "Статистика" в навигации THEN система SHALL перенаправлять на `/dashboard/stats` с общей статистикой

2.10 WHEN пользователь открывает страницу статистики THEN система SHALL отображать селектор периода с кнопками: "Неделя", "Месяц", "Год", "Всё время"

2.11 WHEN пользователь открывает страницу статистики THEN система SHALL отображать сетку из 4 карточек: "Тренировок", "Skill сессий", "WOD сессий", "Новых PR"

2.12 WHEN пользователь открывает страницу статистики THEN система SHALL отображать секцию "Личные рекорды" со списком PR с названием упражнения, датой и значением

2.13 WHEN пользователь открывает страницу статистики THEN система SHALL отображать график "Прогресс по упражнению" с селектором упражнения и детализации (по дням/неделям/месяцам)

#### 4. Страница создания тренировки

2.14 WHEN пользователь добавляет Skill блок THEN система SHALL отображать селектор "Количество подходов" с опциями от 1 до 12

2.15 WHEN пользователь добавляет Skill блок THEN система SHALL отображать поле "Максимальный вес (кг)" для ввода максимального веса

2.16 WHEN пользователь выбирает упражнение в Skill блоке THEN система SHALL отображать подсказку "ℹ️ В прошлый раз: X кг (дата)" если есть история

2.17 WHEN пользователь вводит подходы в Skill блоке THEN система SHALL отображать отдельные инпуты для повторений всех подходов, затем отдельные инпуты для весов каждого подхода

2.18 WHEN пользователь добавляет WOD блок и включает режим "Лесенка" THEN система SHALL отображать поле "Количество раундов" с селектором от 1 до 12

2.19 WHEN пользователь выбирает режим "Лесенка" в WOD блоке THEN система SHALL отображать отдельные инпуты для повторений каждого раунда с плейсхолдерами "Р1", "Р2", "Р3"...

2.20 WHEN пользователь выбирает кардио упражнение (Bike, Row, Run, SkiErg) в WOD блоке THEN система SHALL автоматически скрывать поле "Вес"

2.21 WHEN пользователь вводит результат "For Time" в WOD блоке THEN система SHALL применять маску ввода в формате MM:SS

#### 5. Страница детального просмотра

2.22 WHEN пользователь открывает детальный просмотр тренировки THEN система SHALL отображать кнопку "✏️ Редактировать" в header справа

2.23 WHEN пользователь просматривает Skill блок в деталях THEN система SHALL отображать расчет 1RM для каждого подхода в таблице

2.24 WHEN пользователь просматривает детали тренировки THEN система SHALL отображать дизайн блоков в полном соответствии с эталонными макетами (border-left цвета, отступы, шрифты)

#### 6. Навигация

2.25 WHEN пользователь кликает на "Статистика" в навигации THEN система SHALL перенаправлять на `/dashboard/stats`

2.26 WHEN пользователь переходит на `/dashboard/stats` THEN система SHALL отображать страницу с общей статистикой, личными рекордами и графиком прогресса

### Unchanged Behavior (Regression Prevention)

3.1 WHEN пользователь использует аутентификацию THEN система SHALL CONTINUE TO корректно обрабатывать вход и выход из системы

3.2 WHEN пользователь создает новую тренировку THEN система SHALL CONTINUE TO сохранять данные в базу данных

3.3 WHEN пользователь просматривает список тренировок THEN система SHALL CONTINUE TO загружать данные из базы данных

3.4 WHEN пользователь удаляет тренировку THEN система SHALL CONTINUE TO корректно удалять запись из базы данных

3.5 WHEN пользователь редактирует тренировку THEN система SHALL CONTINUE TO сохранять изменения в базу данных

3.6 WHEN пользователь использует мобильную версию THEN система SHALL CONTINUE TO отображать адаптивный интерфейс

3.7 WHEN пользователь использует темную тему THEN система SHALL CONTINUE TO применять темную цветовую схему

3.8 WHEN пользователь переключается между страницами THEN система SHALL CONTINUE TO сохранять состояние навигации

3.9 WHEN пользователь вводит некорректные данные THEN система SHALL CONTINUE TO отображать валидационные ошибки

3.10 WHEN пользователь использует API THEN система SHALL CONTINUE TO возвращать корректные ответы
