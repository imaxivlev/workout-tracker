# План реализации: Backend API и База данных

## Обзор

Данный план описывает пошаговую реализацию перехода от MVP версии (localStorage) к полноценному веб-приложению с серверной частью на базе Next.js 15, PostgreSQL, Prisma ORM, JWT аутентификацией и PWA функциональностью.

Технологический стек:
- Next.js 15 (App Router) + TypeScript
- PostgreSQL + Prisma ORM
- JWT аутентификация (HTTP-only cookies)
- Service Workers + IndexedDB (оффлайн режим)
- Vercel (деплой) + Supabase/Neon (БД)

## Задачи

**⚠️ ВАЖНО - Порядок выполнения для автономной работы:**

Задачи упорядочены так, чтобы можно было работать автономно. Следующие задачи **требуют участия пользователя** и должны быть выполнены в последнюю очередь:
- **Задача 4** - Email Service (требуется настройка SMTP, регистрация на Яндекс.Почта/Mail.ru)
- **Задача 16** - Деплой на Vercel (требуется регистрация, настройка домена, PostgreSQL на Supabase/Neon)

**Рекомендуемый порядок:**
1. Выполнить задачи 1-3 (настройка проекта, auth, API routes)

4. Дождаться пользователя для задач 4 и 16
