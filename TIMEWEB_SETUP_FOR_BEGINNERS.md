## Часть 1: Подключение к серверу Timeweb через SSH

### Шаг 1: Открой командную строку (терминал)

**Способ 1 (самый простой):**
1. Нажми на клавиатуре `Win + R` (кнопка Windows + буква R)
2. В появившемся окне напиши: `cmd`
3. Нажми `Enter`
4. Откроется черное окно - это командная строка

**Способ 2:**
1. Нажми кнопку "Пуск" (значок Windows внизу слева)
2. Напиши в поиске: `cmd` или `командная строка`
3. Кликни на "Командная строка"

### Шаг 2: Подключись к серверу Timeweb

В черном окне (командной строке) напиши эту команду и нажми `Enter`:

```
ssh cu797814@vh434.timeweb.ru
```

**Что произойдет:**
- Тебя спросят: "Are you sure you want to continue connecting?" 
- Напиши `yes` и нажми `Enter`
- Потом попросят ввести пароль

**Введи пароль:** `s4bZ@y6zUsVj`

⚠️ **ВАЖНО:** Когда вводишь пароль, символы НЕ БУДУТ ВИДНЫ на экране - это нормально! Просто вводи пароль и нажми `Enter`.

**Если всё получилось:**
- Ты увидишь приветствие от сервера
- Строка изменится на что-то вроде: `[cu797814@vh434 ~]$`
- Это значит, что ты подключился к серверу! 🎉

## Часть 2: Установка Node.js на сервере

Теперь ты находишься на сервере Timeweb. Все команды ниже нужно вводить в этом же черном окне.

### Шаг 3: Скачай Node.js

Скопируй эту команду, вставь в командную строку и нажми `Enter`:

```bash
wget https://nodejs.org/dist/v18.19.0/node-v18.19.0-linux-x64.tar.gz
```

**Что происходит:** Скачивается файл с Node.js (это займет 10-30 секунд)

### Шаг 4: Распакуй архив

```bash
tar xf node-v18.19.0-linux-x64.tar.gz
```

**Что происходит:** Распаковывается скачанный архив

### Шаг 5: Переименуй папку

```bash
mv node-v18.19.0-linux-x64 nodejs
```

**Что происходит:** Папка переименовывается в более короткое имя "nodejs"

### Шаг 6: Настрой алиасы (чтобы команды работали)

Скопируй и выполни эти 4 команды **по очереди** (каждую отдельно):

```bash
echo 'alias node="/home/c/cu797814/nodejs/bin/node"' >> ~/.bash_profile
```

```bash
echo 'alias npm="/home/c/cu797814/nodejs/bin/npm"' >> ~/.bash_profile
```

```bash
echo 'alias npx="/home/c/cu797814/nodejs/bin/npx"' >> ~/.bash_profile
```

```bash
echo 'export PATH=$PATH:/home/c/cu797814/nodejs/bin/' >> ~/.bash_profile
```

### Шаг 7: Примени изменения

```bash
source ~/.bash_profile
```

### Шаг 8: Проверь, что Node.js установлен

```bash
node -v
```

**Должно показать:** `v18.19.0`

Если видишь эту версию - отлично! Node.js установлен! ✅

## Часть 6: Установка PM2 и запуск приложения

### Шаг 19: Установи PM2

```bash
npm install -g pm2
```

**Что такое PM2:** Это программа, которая будет следить за твоим приложением и автоматически перезапускать его при сбоях.

### Шаг 20: Запусти приложение

```bash
pm2 start npm --name "workout-tracker-staging" -- start -- -p 3001
```

**Что происходит:** Приложение запускается на порту 3001

### Шаг 21: Сохрани конфигурацию PM2

```bash
pm2 save
```

### Шаг 22: Настрой автозапуск

```bash
pm2 startup
```

**Что произойдет:** PM2 выдаст команду, которую нужно выполнить. Скопируй её и выполни.

Например, это будет что-то вроде:
```bash
sudo env PATH=$PATH:/home/c/cu797814/nodejs/bin pm2 startup systemd -u cu797814 --hp /home/c/cu797814
```

Скопируй эту команду и выполни её.

### Шаг 23: Проверь статус

```bash
pm2 status
```

**Должно показать:** Твоё приложение со статусом "online" ✅

## Часть 7: Настройка домена в панели Timeweb

Теперь нужно зайти в браузер и настроить домен.

### Шаг 24: Открой панель управления Timeweb

1. Открой браузер (Chrome, Firefox, любой)
2. Перейди на сайт: https://timeweb.com/ru/
3. Нажми "Войти" (справа вверху)
4. Введи свои данные для входа

### Шаг 25: Перейди в раздел "Домены"

1. В левом меню найди раздел "Домены"
2. Кликни на него

### Шаг 26: Найди свой домен

1. Найди в списке домен `crossfitapp.ru`
2. Кликни на него

### Шаг 27: Добавь поддомен

1. Найди кнопку "Добавить поддомен" или "Создать поддомен"
2. В поле "Имя поддомена" введи: `test`
3. Полный домен будет: `test.crossfitapp.ru`

### Шаг 28: Настрой проксирование

1. Найди раздел "Проксирование" или "Proxy"
2. Включи проксирование
3. Укажи:
   - **Тип:** HTTP
   - **Порт:** 3001
   - **Путь:** /

### Шаг 29: Включи SSL

1. Найди раздел "SSL сертификат"
2. Выбери "Let's Encrypt" (бесплатный)
3. Нажми "Включить" или "Получить сертификат"

### Шаг 30: Сохрани изменения

Нажми кнопку "Сохранить" внизу страницы.

⏱️ **Подожди 5-10 минут** - изменения применяются не сразу.
